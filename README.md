# Smart Student Management System (ML-Based)

## Project Overview

The Smart Student Management System is a Machine Learning-based application designed to manage student information and analyze academic performance.

## Objectives

- Manage student information efficiently
- Store and organize student records
- Analyze academic performance
- Predict student performance using Machine Learning
- Provide useful insights for academic improvement

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- SQLite
- Machine Learning

## Main Features

- Student Management
- Student Data Storage
- Dashboard
- Academic Performance Analysis
- ML-Based Prediction
- Student Performance Monitoring

## Machine Learning

The system uses student-related academic data to train a Machine Learning model and generate performance predictions.

## Project Files

- `app.py` – Main application
- `database.py` – Database operations
- `model.py` – Machine Learning model
- `model.pkl` – Trained ML model
- `predict.py` – Prediction functionality
- `dashboard.py` – Dashboard
- `add_student.py` – Student data entry
- `test.py` – Testing
- `data.csv` – Dataset
